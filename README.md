# Melamine-Auto-Buffing-Machine
It is a melamine auto-buffing machine which shines the edges of a melamine plate by using a filler and grinder mechanism. 
The operator provides the plate in a rotating wheel on both sides. The wheel then uplifts the plate to be polished by a grinder mechanism. A pneumatic cylinder on both ends is controlled by two level switches. 
The operator can enter the number of times each plate should be polished by the HMI. The counter counts each signal from a sensor pulse triggering. 
As the pulse triggered the desired number the plate is ready for packaging.
